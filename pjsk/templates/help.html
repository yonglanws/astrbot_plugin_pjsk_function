搜索技巧

常用关键词
角色昵称：miku、ick、saki、hnm、shiho、mnr、hrk、airi、shizuku、kohane、an、akito、toya、tsukasa、emu、nene、rui、kanade、mafuyu、ena、mizuki，也支持中文名与常见别名。
团名：ln / mmj / vbs / ws / 25h / vs；团 oc：mmjoc、纯mmj；团 vs：mmjv；纯 VS：vs、纯v。
稀有度：1 / 2 / 3 / 4 星、生日；属性：蓝 / 橙 / 紫 / 粉 / 绿；限定：非限、期间、fes、bfes、cfes、联动。
技能：奶 / 分 / 判；细分技能：团分（组分）、p分、判分、血分、大分；leak 只看未实装卡。
卡牌活动筛选：event123 按活动 ID 筛卡；mnr1 角色第 1 次箱活的卡牌；miku-1 / miku/1 角色最新一张卡。前缀后也可跟分隔符：jp/查卡、pjsk/查卡。
难度：EZ / NM / HD / EX / MA / AP，也接受 easy、normal、hard、expert、master、append。
歌曲特殊写法：id123 按 ID；#123 按 ID；-1 最新发布；mnr1 角色第 1 次箱活；event123 活动书下曲。
